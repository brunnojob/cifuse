# Launch kit

## Short pitch

Your build failed. Your next hour shouldn't. CIFuse groups repeated CI errors, keeps the exact file/line evidence, and compares reports to show new failure signatures. Try it in the browser or run the offline CLI. No account, model or API key.

https://brunnojob.github.io/cifuse/

## Show HN draft

Show HN: CIFuse – offline CI log triage in the browser, CLI and GitHub Actions

I built CIFuse to reduce the repetitive work after a failed CI run: scrolling through duplicate errors, finding the first useful evidence and checking whether the signature appeared before. The browser, CLI and Action share a dependency-free rule engine. It exports JSON/Markdown and compares baseline reports. This is an initial release with illustrative fixtures, not proven root-cause detection. I would especially appreciate sanitized examples where a rule misses a useful diagnostic or matches harmless output.

## LinkedIn draft

The repetitive work after a failed build is often the same: find the useful error, ignore duplicate messages, collect evidence and compare with the previous run.

CIFuse automates that triage with an offline CLI, a browser workbench and a reusable GitHub Action. It groups failure patterns, preserves file and line references, and exports portable reports. English and Brazilian Portuguese are included.

Initial open-source release. Try it and tell me what it misses:
https://github.com/brunnojob/cifuse
