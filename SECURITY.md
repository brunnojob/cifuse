# Security

Do not report live secrets in public issues. For a vulnerability, use GitHub's private vulnerability reporting if enabled; otherwise email contato@brunnodev.store with a minimal sanitized reproducer. Do not include credentials or full private logs.

Reports and job summaries may contain sensitive source text despite best-effort redaction. Read docs/LIMITATIONS.md before sharing them. CIFuse never executes log content. Supported version: latest main until a versioned release is published.
