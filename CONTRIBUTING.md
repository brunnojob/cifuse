# Contributing

Please open an issue for substantial behavior changes. Small fixes and sanitized log fixtures are welcome directly as pull requests.

1. Fork and clone the repository; use Node.js 22 or newer.
2. Run `npm test` and `npm run build`.
3. Add a regression fixture or focused assertion for a behavior change. Include negative cases for new patterns.
4. Update both English and PT-BR user-facing messages.
5. Explain the before/after behavior in the pull request.

Never upload credentials, private URLs, personal data or proprietary logs. Use short representative snippets with invented names and values. No external services or test tokens are needed.

Good first contributions include clearer troubleshooting hints, supported diagnostic formats with positive/negative fixtures, and accessibility improvements. Keep the shared engine dependency-free and usable in browsers. Be respectful; review focuses on behavior and evidence, not the contributor.
